# Backend Maré de Nori Sushi

API Laravel da loja fictícia. Veja a documentação principal em ../README.md e o contrato em ../docs/API.md.

Comandos: composer install; php artisan migrate --seed; php artisan test.

php artisan db:seed troca o catálogo ativo pelo conjunto fictício. Registros anteriores permanecem inativos para preservar o histórico de pedidos.
