# Frontend Maré de Nori Sushi

Storefront e painel em React/Vite para uma loja fictícia de sushi. Veja a documentação principal em ../README.md e o contrato em ../docs/API.md.

Comandos: npm.cmd install; npm.cmd test -- --run; npm.cmd run build; npm.cmd run dev.

A identidade visual de demonstração está em public/ e nas variáveis VITE_STORE_*.
